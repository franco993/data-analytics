# Data Analytics Portfolio 📊🧠

¡Bienvenido a mi repositorio de Analítica de Datos! En este espacio comparto diferentes proyectos prácticos donde aplico técnicas de limpieza, exploración, modelado y visualización de datos para resolver problemas de negocio y extraer información de valor.

---

## 🛠️ Tecnologías y Herramientas
Aquí se listan las principales herramientas utilizadas a lo largo de los proyectos:
* **Lenguajes:** Python (Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn), SQL.
* **Entornos:** Jupyter Notebooks / Google Colab.
* **Bases de Datos:** PostgreSQL / MySQL / SQL Server.
* **Visualización:** Power BI / Tableau (según aplique).
